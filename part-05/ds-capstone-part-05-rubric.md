## How scoring works

Score each required item below from 0 to 3. A score describes how well the work meets that item. Optional extensions do not affect the required score.

| Score | Description |
| --- | --- |
| **0** | The item is missing or there is not enough information to review it. |
| **1** | The item is partly complete, but important required information is missing or unclear. |
| **2** | The item is complete and understandable, with some details or explanations still missing. |
| **3** | The item is complete, specific, clearly explained, and supported by appropriate information. |

## Required criteria

### 1. Presentation and timing

Give a rehearsed 15-minute presentation and leave 5 minutes for questions.

### 2. Slides and visuals

Use a slide deck suitable for a public audience. Include clear, readable charts or other visuals that support the explanation.

### 3. Project explanation

Explain the question, goal, success measure, data, approach, model or analysis, findings, risks, limits, impact, and possible next steps. Explain technical terms in plain language.

### 4. Audience questions

Answer questions about your choices and findings clearly, using evidence from your project where possible.

## Optional extensions

- Discuss how you might check the method over time or make it available in a real service or workflow.
- Create a public interactive chart that lets the audience explore the data and findings.
